# Sounds

Original dark-fantasy music, ambience and effects. Every sound here was synthesized from code (`scripts/audio` in the
theforge monorepo: oscillators, noise, filters and a reverb, no samples and no third-party recordings), so there are no
royalties to pay and nobody to credit. They ship under this project's license.

`audio.json` lists each file with its kind, playback gain, random pitch spread (`vary`) and length. Music and
ambience are meant to loop with a crossfade.
